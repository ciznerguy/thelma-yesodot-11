# פרק 7: פעולות

## בקצרה

- פעולה היא קטע קוד עם שם שאפשר להפעיל כמה פעמים. לפעולה יכולים להיות פרמטרים וערך מוחזר.
- ארבעת סוגי הפעולות: בלי ערך מוחזר ובלי פרמטרים, בלי ערך מוחזר ועם פרמטרים, עם ערך מוחזר ובלי פרמטרים, עם ערך מוחזר ועם פרמטרים.
- פרמטרים רגילים מועברים כעותק של הערך, ולכן שינוי שלהם בתוך הפעולה לא משנה את המשתנה של הקורא.
- משתנים מקומיים קיימים רק בתוך הפעולה שבה הוגדרו.
- בקובץ הקוד כל דוגמה היא פעולה, ופעולות העזר שהיא משתמשת בהן כתובות מיד אחריה.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_VoidNoParameters`: פעולה בלי ערך מוחזר ובלי פרמטרים
2. `Example02_VoidWithParameters`: פעולה בלי ערך מוחזר ועם פרמטרים
3. `Example03_ReturnNoParameters`: פעולה עם ערך מוחזר ובלי פרמטרים
4. `Example04_ReturnWithParameters`: פעולה עם ערך מוחזר ועם פרמטרים
5. `Example05_BoolMethods`: פעולות שמחזירות ערך לוגי
6. `Example06_MethodCallsMethod`: פעולה שקוראת לפעולה אחרת
7. `Example07_ValueIsCopied`: העברת ערך
8. `Example08_LocalVariables`: משתנים מקומיים
9. `Example09_MethodsWithLoops`: פעולות עם לולאות
10. `Example10_RandomMethods`: פעולות עם מספרים אקראיים

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/) ובוחרים בשפה C#.
2. מוחקים את כל הקוד שמופיע בסביבה כברירת מחדל.
3. פותחים את [Program.cs של פרק 7](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בסביבה.
4. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
5. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek07` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 07"
dotnet run
```
