# משימה אסינכרונית 2: פרק 10, מערך דו-ממדי: חידות

**נושא הפרק:** מערך דו-ממדי  
**זמן עבודה מוערך:** עד 90 דקות  
**איפה עובדים ומגישים:** בסטאקס, בתרגיל "פרק 10: משימה 2" שהמורה הקצה לכיתה. מדובר בתוכנית אחת בקובץ אחד.  
**ציון:** כל הגשה נבדקת ומקבלת ציון.

משימה 2 מאתגרת מעט יותר ממשימה 1, אבל גם היא נועדה להסתיים תוך 90 דקות לכל היותר. מומלץ לסיים קודם את משימה 1. בתרגיל הזה תכתבו פעולות על טבלאות: בדיקת ריבוע קסם, טבלה מהופכת, שיאים ומילוי בצורת נחש.

## חלוקת זמן מומלצת

- קריאת ההנחיות והכנת הפרויקט: כ-10 דקות
- הפעולות הראשונות: כ-30 דקות
- הפעולות המאתגרות: כ-30 דקות
- בדיקה מול הפלט הצפוי ותיקונים: כ-10 דקות
- הגשה: כ-10 דקות

## כללים

- כותבים רק בכלים שנלמדו בפרקים 1 עד 10.
- אסור: אופרטור תנאי מקוצר (סימן שאלה ונקודתיים), השמות מקוצרות (פלוס שווה וכדומה), switch, do-while, break, continue ו-try/catch.
- ההגדלה והקטנה ב-1 נכתבות רק כפקודה בפני עצמה.
- ההדפסה היא רק בעזרת Console.WriteLine ו-Console.Write.
- ההערות בקוד נכתבות בעברית.

## שלבי העבודה

1. היכנסו לסטאקס ופתחו את התרגיל "פרק 10: משימה 2" ברשימת התרגילים של הכיתה. כותבים את כל הקוד בתוך התרגיל.
2. כתבו פעולה בשם `Print` שמקבלת טבלה של מספרים שלמים ומדפיסה כל שורה בשורה נפרדת, עם רווח אחרי כל תא.
   דוגמה: לטבלה `{{ 1, 2 }, { 3, 4 }}` היא מדפיסה שתי שורות: `1 2 ` ו-`3 4 `.
3. כתבו פעולה בשם `IsMagic` שמקבלת טבלה ריבועית ומחזירה אמת אם כל הסכומים האלה שווים: סכום כל שורה, סכום כל עמודה, וסכום כל אחד משני האלכסונים. טבלה כזו נקראת ריבוע קסם.
   דוגמה: בטבלה `{{ 2, 7, 6 }, { 9, 5, 1 }, { 4, 3, 8 }}` כל שורה, כל עמודה ושני האלכסונים מסתכמים ב-15, ולכן התוצאה True. בטבלה `{{ 1, 2, 3 }, { 4, 5, 6 }, { 7, 8, 9 }}` הסכומים של השורות הם 6, 15 ו-24, ולכן התוצאה False.
   רמז: חשבו את סכום השורה הראשונה כיעד, והשוו אליו את כל השאר.
4. כתבו פעולה בשם `Transpose` שמקבלת טבלה ומחזירה טבלה חדשה שבה השורות הפכו לעמודות והעמודות לשורות.
   דוגמה: הטבלה `{{ 1, 2, 3 }, { 4, 5, 6 }}` (2 שורות ו-3 עמודות) הופכת לטבלה של 3 שורות ו-2 עמודות: `{{ 1, 4 }, { 2, 5 }, { 3, 6 }}`.
   רמז: התא בשורה r ובעמודה c עובר לשורה c ולעמודה r. שימו לב שגודל הטבלה החדשה הפוך.
5. כתבו פעולה בשם `CountPeaks` שמחזירה כמה תאים הם שיא. תא הוא שיא אם הוא גדול ממש מכל שכניו: זה שמעליו, מתחתיו, משמאלו ומימינו, אבל רק מאלה שקיימים. לתא בקצה הטבלה יש פחות שכנים.
   דוגמה: בטבלה `{{ 1, 5, 1 }, { 4, 9, 2 }, { 1, 3, 8 }}` התא 9 גדול מכל ארבעת שכניו (5, 4, 2, 3), והתא 8 בפינה גדול משני שכניו (2 ו-3). לכן התוצאה היא 2.
   רמז: לכל תא התחילו מההנחה שהוא שיא, ושנו אותה לשקר אם מצאתם שכן קיים שאינו קטן ממנו. בדקו שהשכן בתוך גבולות הטבלה לפני שניגשים אליו.
6. כתבו פעולה בשם `FillSnake` שמקבלת מספר n ומחזירה טבלה n על n שמלאה במספרים מ-1 ואילך, שורה אחרי שורה. השורה הראשונה מתמלאת משמאל לימין, השנייה מימין לשמאל, וכך לסירוגין.
   דוגמה: `FillSnake(3)` מחזירה:
   ```
   1 2 3
   6 5 4
   7 8 9
   ```
   רמז: בשורות עם מספר זוגי (0, 2, ...) הולכים מעמודה 0 קדימה, ובשורות עם מספר אי זוגי הולכים מהעמודה האחרונה אחורה. משתנה אחד סופר את המספר הבא להכנסה.
7. ב-`Main` קראו לפעולות על: `{{2,7,6},{9,5,1},{4,3,8}}` ועל `{{1,2,3},{4,5,6},{7,8,9}}` (ריבוע קסם), על `{{1,2,3},{4,5,6}}` (הפיכה, ואחריה `Print`), על `{{1,5,1},{4,9,2},{1,3,8}}` (שיאים), ועל `FillSnake(4)` (ואחריו `Print`). הדפיסו תווית לפני כל תוצאה, כמו `Magic square: `.
