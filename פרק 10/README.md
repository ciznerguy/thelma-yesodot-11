# פרק 10: מערך דו-ממדי

## בקצרה

- מערך דו-ממדי הוא טבלה של שורות ועמודות, והגישה לתא נעשית בעזרת מספר שורה ומספר עמודה.
- מעבר על כל התאים נעשה בשתי לולאות מקוננות, והאורכים מתקבלים מהמימד הראשון והשני.
- חישוב לפי שורות מאפס את הסכום בתוך הלולאה החיצונית, וחישוב לפי עמודות הופך את סדר הלולאות.
- אלכסונים, חיפוש, הופכי של טבלה ולוח משחק הם דוגמאות לשימושים.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_CreateMatrix`: יצירת מערך דו-ממדי
2. `Example02_PrintMatrix`: הדפסת טבלה
3. `Example03_SumOfMatrix`: סכום כל התאים
4. `Example04_RowSums`: סכום של כל שורה
5. `Example05_ColumnSums`: סכום של כל עמודה
6. `Example06_Diagonals`: אלכסונים
7. `Example07_SearchInMatrix`: חיפוש ערך בטבלה
8. `Example08_MultiplicationTable`: לוח הכפל
9. `Example09_Transpose`: טבלה מהופכת
10. `Example10_BoardGame`: לוח משחק עם תווים

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/) ובוחרים בשפה C#.
2. מוחקים את כל הקוד שמופיע בסביבה כברירת מחדל.
3. פותחים את [Program.cs של פרק 10](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בסביבה.
4. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
5. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek10` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 10"
dotnet run
```
