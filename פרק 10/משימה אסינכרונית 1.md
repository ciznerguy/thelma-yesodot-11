# משימה אסינכרונית 1: פרק 10, מערך דו-ממדי: דוח ציונים לכיתה

**נושא הפרק:** מערך דו-ממדי  
**זמן עבודה מוערך:** עד 90 דקות  
**איפה עובדים ומגישים:** בסטאקס, בתרגיל "פרק 10: משימה 1" שהמורה הקצה לכיתה. מדובר בתוכנית אחת בקובץ אחד.  
**ציון:** כל הגשה נבדקת ומקבלת ציון.

בטבלה יש ציונים של ארבעה תלמידים בשלושה מבחנים. שורה היא תלמיד ועמודה היא מבחן.

## חלוקת זמן מומלצת

- קריאת ההנחיות והכנת הפרויקט: כ-10 דקות
- ממוצע לכל תלמיד: כ-30 דקות
- ממוצע לכל מבחן, התלמיד המצטיין וספירת כישלונות: כ-25 דקות
- בדיקה מול הפלט הצפוי ותיקונים: כ-15 דקות
- הגשה: כ-10 דקות

## כללים

- כותבים רק בכלים שנלמדו בפרקים 1 עד 10.
- אסור: אופרטור תנאי מקוצר (סימן שאלה ונקודתיים), השמות מקוצרות (פלוס שווה וכדומה), switch, do-while, break, continue ו-try/catch.
- ההגדלה והקטנה ב-1 נכתבות רק כפקודה בפני עצמה.
- ההדפסה היא רק בעזרת Console.WriteLine ו-Console.Write.
- ההערות בקוד נכתבות בעברית.

## שלבי העבודה

1. היכנסו לסטאקס ופתחו את התרגיל "פרק 10: משימה 1" ברשימת התרגילים של הכיתה. כותבים את כל הקוד בתוך התרגיל.
2. ב-`Main` הגדירו טבלה של ציונים. כל שורה היא תלמיד, וכל עמודה היא מבחן:
   ```
   int[,] marks =
   {
       { 90, 85, 100 },
       { 60, 70, 55 },
       { 45, 50, 60 },
       { 100, 95, 98 }
   };
   ```
3. לכל תלמיד (שורה) חשבו את הממוצע של שלושת המבחנים שלו, והדפיסו אותו מעוגל לשתי ספרות אחרי הנקודה. בשורה הראשונה הממוצע הוא (90 ועוד 85 ועוד 100) חלקי 3, כלומר 91.67.
   רמז: הסכום מתאפס בתחילת כל שורה, כלומר בתוך הלולאה החיצונית.
4. לכל מבחן (עמודה) חשבו את הממוצע שלו על פני כל התלמידים, והדפיסו. כאן הלולאה החיצונית עוברת על העמודות והפנימית על השורות. בעמודה הראשונה הממוצע הוא (90 ועוד 60 ועוד 45 ועוד 100) חלקי 4, כלומר 73.75.
5. מצאו את מספר התלמיד עם הממוצע הגבוה ביותר, והדפיסו אותו. הספירה מתחילה מאפס, ולכן התלמיד הראשון הוא מספר 0.
6. ספרו כמה ציונים בכל הטבלה נמוכים מ-56, והדפיסו.
7. אל תכתבו מספרים קבועים כמו 4 או 3 בלולאות. קבלו את מספר השורות ואת מספר העמודות בעזרת `marks.GetLength(0)` ו-`marks.GetLength(1)`.
