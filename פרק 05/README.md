# פרק 5: לולאות for

## בקצרה

- לולאה חוזרת על קטע קוד. לולאה כזו מורכבת מהתחלה, תנאי וקידום.
- דפוסים נפוצים: סכום, מונה, מכפלה, בדיקת מחלקים וראשוניות בעזרת דגל לוגי.
- לולאה בתוך לולאה מתאימה לדפוסים של שורות ועמודות.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_PrintStars`: לולאה ראשונה, הדפסת כוכביות
2. `Example02_CountUp`: ספירה קדימה
3. `Example03_CountDownAndSteps`: ספירה לאחור וקפיצות
4. `Example04_SumOfNumbers`: סכום של מספרים
5. `Example05_EvenNumbers`: מספרים זוגיים, בשתי דרכים
6. `Example06_Factorial`: עצרת
7. `Example07_PowerByLoop`: חזקה בעזרת לולאה
8. `Example08_CountDivisors`: ספירת מחלקים
9. `Example09_IsPrime`: האם המספר ראשוני
10. `Example10_StarTriangle`: משולש כוכביות, לולאה בתוך לולאה

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **+** (הוספת קובץ) ויוצרים קובץ בשם `Main.cs`.
3. מוודאים שהלשונית הפעילה היא `Main.cs` ולא `Main.java`. בכותרת הפלט צריך להופיע "הרצה של קובץ: Main.cs".
4. פותחים את [Program.cs של פרק 5](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים ב-`Main.cs`.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הקוד הודבק בקובץ `Main.java`. צריך להדביק אותו ב-`Main.cs`.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek05` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 05"
dotnet run
```
