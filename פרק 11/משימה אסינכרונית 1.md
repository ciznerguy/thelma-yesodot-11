# משימה אסינכרונית 1: פרק 11, מחלקות והכלה: ספרייה

**נושא הפרק:** מחלקות ועצמים (כולל הכלת עצמים)  
**זמן עבודה מוערך:** עד 90 דקות  
**איפה עובדים:** בסביבת הקוד של סטאקס, בפרויקט חדש בשפת C#. מדובר בתוכנית אחת בקובץ אחד.

תבנו ספרייה קטנה. לכל ספר יש מחבר, והספרייה מחזיקה מערך של ספרים. זו הכלה של עצמים בשתי רמות.

## חלוקת זמן מומלצת

- קריאת ההנחיות, מחלקת המחבר ומחלקת הספר: כ-30 דקות
- מחלקת הספרייה ופעולותיה: כ-30 דקות
- כתיבת הקוד הראשי: כ-10 דקות
- בדיקה מול הפלט הצפוי ותיקונים: כ-10 דקות
- הגשה: כ-10 דקות

## כללים

- כותבים רק בכלים שנלמדו בפרקים 1 עד 11.
- אסור: אופרטור תנאי מקוצר (סימן שאלה ונקודתיים), השמות מקוצרות (פלוס שווה וכדומה), switch, do-while, break, continue ו-try/catch.
- ההגדלה והקטנה ב-1 נכתבות רק כפקודה בפני עצמה.
- ההדפסה היא רק בעזרת Console.WriteLine ו-Console.Write.
- ההערות בקוד נכתבות בעברית.

## שלבי העבודה

1. פתחו פרויקט חדש בסביבת הקוד של סטאקס: **סביבת קוד** ← **פרויקט חדש** ← שם לפרויקט ← שפת **C#**.
2. כתבו מחלקה `Author` (מחבר). לכל מחבר יש שם ושנת לידה, כתכונות פרטיות. הוסיפו פעולה בונה שמקבלת את שניהם, מאפיין קריאה `Name` שמחזיר את השם, ופעולת טקסט שמחזירה את הפרטים בצורה:
   ```
   Dana Cohen (1980)
   ```
3. כתבו מחלקה `Book` (ספר). לכל ספר יש כותרת, מחבר (עצם מסוג `Author`), מספר עמודים ומחיר. זו הכלה של עצם בתוך עצם: הספר מכיל מחבר. הוסיפו פעולה בונה, מאפייני קריאה `Pages`, `Price` ו-`Author`, ופעולת טקסט בצורה:
   ```
   Sea Tales by Dana Cohen (1980), 200 pages, 59.9 NIS
   ```
   רמז: את הטקסט של המחבר מקבלים אוטומטית כשמחברים את עצם המחבר למחרוזת.
4. כתבו מחלקה `Library` (ספרייה) עם מערך של חמישה ספרים ומונה של מספר הספרים שנוספו. הוסיפו את הפעולות האלה:
   - `Add`: מקבלת ספר. אם יש מקום במערך, שומרת אותו במקום הפנוי הבא, מגדילה את המונה ומחזירה אמת. אם המערך מלא, מחזירה שקר.
   - `TotalPrice`: מחזירה את סכום המחירים של כל הספרים שנוספו.
   - `Longest`: מחזירה את הספר עם מספר העמודים הגדול ביותר.
   - `CountByAuthor`: מקבלת שם מחבר, ומחזירה כמה ספרים נכתבו על ידי המחבר הזה. את שם המחבר של ספר מקבלים דרך `book.Author.Name`.
   - מאפיין קריאה `Count` למספר הספרים בספרייה.
5. ב-`Main` צרו שני מחברים: `Dana Cohen` (1980) ו-`Yoav Levi` (1975), וצרו ספרייה.
6. הוסיפו לספרייה, בדיוק לפי הסדר, ושמרו את התוצאה של כל הוספה: `Sea Tales` (של Dana, 200 עמודים, 59.9), `Mountain Paths` (של Yoav, 350, 79.5), `Night Sky` (של Dana, 120, 45), `City Lights` (של Yoav, 280, 65), `Quiet River` (של Dana, 90, 39.9), ו-`One Too Many` (של Dana, 10, 10). הדפיסו את התוצאה של כל הוספה. הספר השישי לא ייכנס, כי הספרייה מכילה רק חמישה, ולכן התוצאה שלו תהיה False.
7. הדפיסו את מספר הספרים, את המחיר הכולל, את הספר הארוך ביותר ואת מספר הספרים של `Dana Cohen`.
