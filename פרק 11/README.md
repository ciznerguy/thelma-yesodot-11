# פרק 11: מחלקות ועצמים (כולל הכלת עצמים)

## בקצרה

- מחלקה היא תבנית ליצירת עצמים. היא מגדירה תכונות פרטיות, פעולה בונה, מאפיינים ופעולות.
- עצם נוצר בעזרת מילה שמורה ליצירה, ולכל עצם יש ערכים משלו.
- הכלת עצמים: תכונה של מחלקה היא עצם של מחלקה אחרת, למשל לעיגול יש מרכז שהוא נקודה.
- משתנה של עצם מחזיק הפנייה, ולכן שתי השמות של עצם מצביעות על אותו עצם.
- המחלקות כתובות בהמשך אותו קובץ, אחרי הפעולה הראשית.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_CreateObjects`: יצירת עצמים
2. `Example02_PropertiesAndValidation`: מאפיינים ובדיקת תקינות
3. `Example03_ObjectMethods`: פעולות של עצם
4. `Example04_TwoConstructors`: שתי פעולות בונות
5. `Example05_ContainmentCircleAndPoint`: הכלת עצמים
6. `Example06_BankAccount`: חשבון בנק
7. `Example07_ContainmentPersonAndAddress`: הכלה של אדם וכתובת
8. `Example08_ArrayOfObjects`: מערך של עצמים
9. `Example09_ObjectsAreReferences`: עצמים הם הפניות
10. `Example10_ClassWithArray`: מחלקה שמחזיקה מערך

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/) ובוחרים בשפה C#.
2. מוחקים את כל הקוד שמופיע בסביבה כברירת מחדל.
3. פותחים את [Program.cs של פרק 11](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בסביבה.
4. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
5. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek11` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 11"
dotnet run
```
