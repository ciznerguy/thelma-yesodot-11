פעולות

עם משימה
  • פעולה היא קטע קוד עם שם שאפשר להפעיל כמה פעמים. לפעולה יכולים להיות פרמטרים וערך מוחזר.
  • ארבעת סוגי הפעולות: בלי ערך מוחזר ובלי פרמטרים, בלי ערך מוחזר ועם פרמטרים, עם ערך מוחזר ובלי פרמטרים, עם ערך מוחזר ועם פרמטרים.
  • פרמטרים רגילים מועברים כעותק של הערך, ולכן שינוי שלהם בתוך הפעולה לא משנה את המשתנה של הקורא.
  • משתנים מקומיים קיימים רק בתוך הפעולה שבה הוגדרו.
  • בקובץ הקוד כל דוגמה היא פעולה, ופעולות העזר שהיא משתמשת בהן כתובות מיד אחריה.

  • תווים הם מספרים, ולכן אפשר לחשב איתם, למשל למצוא מקום של אות באלפבית.

הורשה (כולל מחלקה מופשטת)

עם משימה
  • הורשה מאפשרת למחלקת בן לקבל תכונות ופעולות ממחלקת אב. הקשר ביניהן הוא מסוג הוא: כלב הוא חיה.
  • הפעולה הבונה של הבן קוראת לפעולה הבונה של האב. פעולה וירטואלית של האב אפשר להחליף בבן.
  • תכונה מוגנת זמינה ליורשים. אפשר להפעיל פעולה של האב מתוך הבן.
  • מחלקה מופשטת לא ניתנת ליצירה. היא יכולה להכיל פעולות מופשטות שכל יורש חייב לממש.
  • המחלקות כתובות בקובץ נפרד מהקובץ הראשי.

איך פותחים ומריצים

נדרש Visual Studio 2022 (או חדש יותר) או ערכת הפיתוח של .NET 8.

  1. מורידים את המאגר
    ב-GitHub: Code ואז Download ZIP, או שכפול בעזרת הפקודה.
    git clone https://github.com/ciznerguy/thelma-yesodot-11.git
  2. פותחים את הפתרון
    לוחצים פעמיים על הקובץ ThelmaYesodot11.sln כדי לפתוח אותו ב-Visual Studio.
  3. בוחרים פרק
    לחיצה ימנית על הפרויקט של הפרק (למשל Perek05) ואז Set as Startup Project.
  4. מריצים
    לוחצים על הכפתור הירוק Start. ב-Main כל שורה מפעילה דוגמה, ואפשר לסמן שורות בהערה כדי לדלג עליהן.

משורת הפקודה:

dotnet build
cd "פרק 5"
dotnet run
