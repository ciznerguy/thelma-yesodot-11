# יסודות מדעי המחשב בשפת C#, כיתה י"א

### 🌐 [לאתר הקורס: ciznerguy.github.io/thelma-yesodot-11](https://ciznerguy.github.io/thelma-yesodot-11/)

סביבת לימוד בעברית לקורס **יסודות מדעי המחשב** בכיתה י"א, בתלמה ילין. החומר בנוי על פי המצגות של משרד החינוך (לומדות), ומיועד לתכנית הלימודים של יסודות מדעי המחשב.

## מה יש כאן

- פתרון אחד של Visual Studio (`ThelmaYesodot11.sln`) עם 14 פרויקטים, פרויקט לכל פרק.
- בכל פרק דוגמאות קוד מוכנות להרצה. כל דוגמה היא פעולה סטטית נפרדת, וההערות בקוד כתובות בעברית.
- בפרקים 7 עד 14 גם שתי משימות אסינכרוניות בכל פרק (השנייה מאתגרת מעט יותר), שאפשר לסיים כל אחת תוך 90 דקות. המשימות מוגשות בסטאקס, וכל הגשה מקבלת ציון.
- בסוף כל מבחן תרגול כפתור שמעתיק את התוצאות ופותח את Gemini ללמידה מותאמת אישית. [הוראות](https://ciznerguy.github.io/thelma-yesodot-11/gemini.html)

## איך מריצים בסטאקס

לכל פרק קובץ קוד אחד, `Program.cs`. בלי להתקין כלום:

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח, פותחים את `Program.cs` של הפרק הרצוי (הקישור "קוד" ברשימה למעלה), מעתיקים את כל התוכן ומדביקים.
4. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
5. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת מסמנים את השאר בהערה (`//`).

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

**דרישות:** Visual Studio 2022 (או חדש יותר) עם עומס העבודה של פיתוח שולחן עבודה ב-.NET, או ערכת הפיתוח של .NET 8.

1. מורידים את המאגר: **Code** ואז **Download ZIP**, ומחלצים. או משכפלים בעזרת הפקודה:

   ```bash
   git clone https://github.com/ciznerguy/thelma-yesodot-11.git
   ```

2. פותחים את הקובץ `ThelmaYesodot11.sln` ב-Visual Studio.
3. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט של הפרק הרצוי (למשל `Perek05`) ובוחרים **Set as Startup Project**, ואז **Start**.

**משורת הפקודה:**

```bash
dotnet build
cd "פרק 05"
dotnet run
```

## הערות על הקוד

- הפלט של התוכניות באנגלית, כדי שהוא יוצג נכון בחלון ההרצה בכל מחשב.
- הקוד נכתב בהתאם לתכנית הלימודים: בלי אופרטור תנאי מקוצר, בלי השמות מקוצרות, בלי switch, do-while, break, continue ו-try/catch. פעולות מתמטיות מוגבלות ל-Abs, Max, Min, Pow, Round ו-Sqrt.
- מפעולות המחרוזת נעשה שימוש רק במה שנכלל בבגרות: אורך, גישה לתו לפי מקום, IndexOf ו-Contains.
- במחלקות ניגשים לתכונות פרטיות דרך פעולות Get ו-Set, כמו בבגרות, ולא דרך מאפיינים של C#.
- בפרקים 11 עד 14 המחלקות כתובות בהמשך אותו קובץ, אחרי הפעולה הראשית, כך שאפשר להעתיק קובץ אחד בלבד.
