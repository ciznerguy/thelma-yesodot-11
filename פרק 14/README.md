# פרק 14: ממשקים

## בקצרה

- ממשק הוא חוזה: רשימה של פעולות שמחלקה שמממשת אותו מתחייבת לכתוב. אין בו מימוש.
- מחלקה יכולה לרשת מאב אחד בלבד, אבל לממש כמה ממשקים.
- משתנה, מערך או פרמטר מסוג ממשק מחזיקים עצמים מכל מחלקה שמממשת אותו, גם אם המחלקות לא קשורות בהורשה.
- אי אפשר ליצור עצם מממשק עצמו.
- המחלקות והממשקים כתובים בהמשך אותו קובץ, אחרי הפעולה הראשית.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_ImplementingInterface`: מימוש ממשק
2. `Example02_TwoInterfaces`: מחלקה שמממשת כמה ממשקים
3. `Example03_InterfaceAsVariableType`: ממשק כטיפוס של משתנה
4. `Example04_ArrayOfInterface`: מערך של ממשק
5. `Example05_MethodWithInterfaceParameter`: פעולה שמקבלת ממשק כפרמטר
6. `Example06_ShapesInterface`: ממשק של צורות
7. `Example07_UnrelatedClasses`: מחלקות שאינן קשורות זו לזו
8. `Example08_TotalPayments`: סכום כל התשלומים
9. `Example09_AbstractClassAndInterface`: מחלקה מופשטת וממשק יחד
10. `Example10_FilteringByInterface`: אותו עצם, כמה זהויות

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 14](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek14` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 14"
dotnet run
```
