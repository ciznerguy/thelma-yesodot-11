# פרק 2: אופרטורים וביטויים לוגיים

## בקצרה

- אופרטורים חשבוניים: חיבור, חיסור, כפל, חילוק ושארית, וסדר הפעולות ביניהם.
- שארית בחילוק מאפשרת לבדוק זוגיות, התחלקות, ולחלץ ספרות ממספר.
- אופרטורי השוואה נותנים ערך לוגי, ואופרטורים לוגיים (וגם, או, לא) מחברים ערכים לוגיים.
- הגדלה והקטנה ב-1 נכתבות כפקודה בפני עצמה.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_ArithmeticOperators`: אופרטורים חשבוניים
2. `Example02_IntegerDivisionAndRemainder`: חילוק שלמים ושארית
3. `Example03_Precedence`: סדר פעולות חשבון
4. `Example04_EvenOrOdd`: זוגי או אי זוגי
5. `Example05_DigitsOfNumber`: ספרות של מספר
6. `Example06_RelationalOperators`: אופרטורי השוואה
7. `Example07_LogicalOperators`: אופרטורים לוגיים
8. `Example08_BoolVariables`: משתנים לוגיים
9. `Example09_RangeCheck`: בדיקת טווח
10. `Example10_IncrementAsStatement`: הגדלה והקטנה ב-1

## איך מריצים

**ב-Visual Studio:**

1. פותחים את הקובץ `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט `Perek02` ובוחרים **Set as Startup Project**.
3. לוחצים על הכפתור הירוק **Start** (או על Ctrl+F5).
4. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

**משורת הפקודה (נדרש .NET 8):**

```bash
cd "פרק 2"
dotnet run
```
