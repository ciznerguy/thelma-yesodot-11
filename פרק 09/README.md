# פרק 9: מערכים

## בקצרה

- מערך הוא אוסף של ערכים מאותו טיפוס תחת שם אחד, ולכל ערך מקום שמתחיל באפס.
- מעבר על מערך נעשה בלולאה מאפס ועד האורך פחות אחד.
- אלגוריתמים בסיסיים: סכום, ממוצע, מקסימום ומינימום, חיפוש, ספירה לפי תנאי והיפוך.
- מערך שנשלח לפעולה נשלח כהפניה, ולכן שינוי בתוך הפעולה משנה את המערך המקורי.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_CreateArray`: יצירת מערך
2. `Example02_PrintArray`: הדפסת מערך
3. `Example03_SumAndAverage`: סכום וממוצע
4. `Example04_MaxAndMin`: הערך הגדול והקטן ביותר
5. `Example05_SearchInArray`: חיפוש איבר
6. `Example06_CountCondition`: ספירת איברים לפי תנאי
7. `Example07_ReverseArray`: היפוך מערך במקום
8. `Example08_ArrayAsParameter`: מערך כפרמטר לפעולה
9. `Example09_RandomArray`: מערך של מספרים אקראיים
10. `Example10_FrequencyArray`: מערך שסופר
11. `Example11_ArrayOfStrings`: מערך של מחרוזות

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/) ובוחרים בשפה C#.
2. מוחקים את כל הקוד שמופיע בסביבה כברירת מחדל.
3. פותחים את [Program.cs של פרק 9](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בסביבה.
4. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
5. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek09` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 09"
dotnet run
```
