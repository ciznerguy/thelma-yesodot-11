# פרק 8: מחרוזות

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** [לקורס באתר קמפוס](https://app.campus.gov.il/learning/course/course-v1:MoE+EDU_Matric_ComputerScienceA_HE+2023_1/home), ובקורס פותחים את **פרק 8**.

## בקצרה

- מחרוזת היא רצף תווים. התו הראשון נמצא במקום אפס, והאחרון באורך פחות אחד.
- הפעולות שנכללות בבגרות: אורך, תו במקום, חיפוש (`IndexOf`) והכלה (`Contains`). חלק ממחרוזת או החלפת תווים בונים בעזרת לולאה.
- מחרוזת אינה משתנה: כדי לקבל תוצאה אחרת בונים מחרוזת חדשה ושומרים אותה.
- תווים הם מספרים, ולכן אפשר לחשב איתם, למשל למצוא מקום של אות באלפבית.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_LengthAndIndex`: אורך המחרוזת ותו במקום מסוים
2. `Example02_PrintEachChar`: מעבר על כל התווים
3. `Example03_PartOfString`: חלק ממחרוזת בעזרת לולאה
4. `Example04_IndexOfAndContains`: חיפוש בתוך מחרוזת
5. `Example05_ReplaceChar`: החלפת תו במחרוזת
6. `Example06_CountLetter`: ספירת אות במחרוזת
7. `Example07_ReverseString`: היפוך מחרוזת
8. `Example08_Palindrome`: האם המילה פלינדרום
9. `Example09_CharCodes`: קודים של תווים
10. `Example10_StringsAreImmutable`: מחרוזת אינה משתנה

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 8](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek08` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 08"
dotnet run
```
