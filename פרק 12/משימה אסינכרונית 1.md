# משימה אסינכרונית 1: פרק 12, הורשה ומחלקה מופשטת: בית הספר

**נושא הפרק:** הורשה (כולל מחלקה מופשטת)  
**זמן עבודה מוערך:** עד 90 דקות  
**איפה עובדים ומגישים:** בסטאקס, בתרגיל "פרק 12: משימה 1" שהמורה הקצה לכיתה. מדובר בתוכנית אחת בקובץ אחד.  
**ציון:** כל הגשה נבדקת ומקבלת ציון.

תבנו היררכיה של חברי קהילה בבית ספר, עם מחלקת אב מופשטת וכמה מחלקות יורשות.

## חלוקת זמן מומלצת

- קריאת ההנחיות ומחלקת האב: כ-20 דקות
- מחלקות התלמיד והמורה: כ-20 דקות
- מחלקת הנציג (יורשת מתלמיד): כ-15 דקות
- כתיבת הקוד הראשי ובדיקה: כ-25 דקות
- הגשה: כ-10 דקות

## כללים

- כותבים רק בכלים שנלמדו בפרקים 1 עד 12.
- אסור: אופרטור תנאי מקוצר (סימן שאלה ונקודתיים), השמות מקוצרות (פלוס שווה וכדומה), switch, do-while, break, continue ו-try/catch.
- ההגדלה והקטנה ב-1 נכתבות רק כפקודה בפני עצמה.
- ההדפסה היא רק בעזרת Console.WriteLine ו-Console.Write.
- ההערות בקוד נכתבות בעברית.
- לתכונות פרטיות ניגשים רק דרך פעולות קבלה ושינוי (`GetX` ו-`SetX`), כמו בבגרות. לא משתמשים במאפיינים של C# (get ו-set בתוך סוגריים מסולסלים).

## שלבי העבודה

1. היכנסו לסטאקס ופתחו את התרגיל "פרק 12: משימה 1" ברשימת התרגילים של הכיתה. כותבים את כל הקוד בתוך התרגיל.
2. כתבו מחלקה מופשטת `Member` (חבר בבית הספר). יש לה שם, בתכונה מוגנת (כדי שמחלקות יורשות יוכלו להשתמש בו), פעולה בונה שמקבלת את השם, ופעולה מופשטת `Describe` שמחזירה מחרוזת. פעולה מופשטת היא פעולה בלי גוף, וכל יורש חייב לכתוב אותה בעצמו.
3. כתבו מחלקה `Student` (תלמיד) שיורשת מ-`Member`. יש לה גם כיתה (מספר שלם), בתכונה מוגנת. הפעולה הבונה מקבלת שם וכיתה, ומעבירה את השם לפעולה הבונה של האב בעזרת `: base(name)`. הפעולה `Describe` מחזירה:
   ```
   Student Noa, grade 11
   ```
4. כתבו מחלקה `Teacher` (מורה) שיורשת מ-`Member`, עם מקצוע. הפעולה `Describe` מחזירה:
   ```
   Teacher Avi, teaches Math
   ```
5. כתבו מחלקה `Prefect` (נציג כיתה) שיורשת מ-`Student`, עם תפקיד. הפעולה `Describe` שלה קוראת קודם לפעולה של האב (`base.Describe()`), ומוסיפה בסוף את התפקיד:
   ```
   Student Dan, grade 12, duty: library
   ```
6. ב-`Main` צרו תלמידה `Noa` בכיתה 11, מורה `Avi` שמלמד `Math`, ונציג `Dan` בכיתה 12 בתפקיד `library`. הדפיסו את הפעולה `Describe` של כל אחד.
7. שמרו את הנציג במשתנה מסוג `Member`, ואז הדפיסו שוב את `Describe` שלו דרך המשתנה הזה. התוצאה צריכה להיות זהה, כי מופעלת הפעולה של העצם האמיתי.
8. כתבו בהערה בלבד שורה שיוצרת עצם ישירות מהמחלקה `Member`. לא להשאיר אותה כקוד שרץ, כי היא גורמת לשגיאת קומפילציה. הוסיפו הערה בעברית שמסבירה למה אי אפשר ליצור עצם ממחלקה מופשטת.

## הפלט הצפוי

הפלט של התוכנית שלכם צריך להיות זהה לחלוטין לפלט הבא, כולל רווחים ואותיות:

```
Student Noa, grade 11
Teacher Avi, teaches Math
Student Dan, grade 12, duty: library
Through a Member variable: Student Dan, grade 12, duty: library
```

## אתגר רשות

הוסיפו מחלקה `Principal` שיורשת מ-`Teacher`, ומוסיפה את שם בית הספר לתיאור. האתגר אינו חובה ואינו משפיע על ההגשה הבסיסית.
