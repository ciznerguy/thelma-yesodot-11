# פרק 12: הורשה (כולל מחלקה מופשטת)

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** [לקורס באתר קמפוס](https://app.campus.gov.il/learning/course/course-v1:MoE+EDU_Matric_ComputerScienceA_HE+2023_1/home), ובקורס פותחים את **פרק 12**.

## בקצרה

- הורשה מאפשרת למחלקת בן לקבל תכונות ופעולות ממחלקת אב. הקשר ביניהן הוא מסוג הוא: כלב הוא חיה.
- הפעולה הבונה של הבן קוראת לפעולה הבונה של האב. פעולה וירטואלית של האב אפשר להחליף בבן.
- תכונה מוגנת זמינה ליורשים. אפשר להפעיל פעולה של האב מתוך הבן.
- מחלקה מופשטת לא ניתנת ליצירה. היא יכולה להכיל פעולות מופשטות שכל יורש חייב לממש.
- המחלקות כתובות בהמשך אותו קובץ, אחרי הפעולה הראשית.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_InheritedMembers`: תכונות ופעולות שעוברות בירושה
2. `Example02_ChildHasNewMembers`: יורש יכול להוסיף דברים חדשים
3. `Example03_OverridingMethods`: החלפת פעולה של האב
4. `Example04_BaseConstructor`: הפעולה הבונה של היורש
5. `Example05_CallingBaseMethod`: קריאה לפעולה של האב מתוך הבן
6. `Example06_MultiLevelInheritance`: הורשה בכמה רמות
7. `Example07_AbstractClass`: מחלקה מופשטת
8. `Example08_AbstractCannotBeCreated`: אי אפשר ליצור עצם ממחלקה מופשטת
9. `Example09_ParentVariableHoldsChild`: משתנה של האב יכול להחזיק עצם של בן
10. `Example10_ArrayOfParents`: מערך של עצמים מסוג האב

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 12](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek12` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 12"
dotnet run
```
