# פרק 3: ספרייה מתמטית ומחלקת אקראי

## בקצרה

- הספרייה המתמטית בפרק זה: ערך מוחלט, מקסימום, מינימום, חזקה, שורש ועיגול.
- מחלקת אקראי מגרילה מספרים: ההגרלה מתחילה מאפס, והחסם העליון אינו נכלל.
- בדוגמאות עם הגרלה הפלט שונה בכל הרצה.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_AbsMaxMin`: ערך מוחלט, מקסימום ומינימום
2. `Example02_Power`: חזקה
3. `Example03_SquareRoot`: שורש ריבועי
4. `Example04_Round`: עיגול
5. `Example05_Distance`: מרחק בין שתי נקודות
6. `Example06_Hypotenuse`: יתר במשולש ישר זווית
7. `Example07_RandomNumber`: מספר אקראי
8. `Example08_RandomRange`: מספר אקראי בטווח
9. `Example09_RandomLetter`: אות אקראית
10. `Example10_RandomDecision`: הגרלה והחלטה

## איך מריצים

**ב-Visual Studio:**

1. פותחים את הקובץ `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט `Perek03` ובוחרים **Set as Startup Project**.
3. לוחצים על הכפתור הירוק **Start** (או על Ctrl+F5).
4. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

**משורת הפקודה (נדרש .NET 8):**

```bash
cd "פרק 03"
dotnet run
```
