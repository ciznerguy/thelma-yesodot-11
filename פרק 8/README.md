# פרק 8: מחרוזות

## בקצרה

- מחרוזת היא רצף תווים. התו הראשון נמצא במקום אפס, והאחרון באורך פחות אחד.
- פעולות עיקריות: אורך, תו במקום, חיתוך, חיפוש, הכלה, אותיות גדולות וקטנות, והחלפה.
- מחרוזת אינה משתנה: כל פעולה מחזירה מחרוזת חדשה שצריך לשמור.
- תווים הם מספרים, ולכן אפשר לחשב איתם, למשל למצוא מקום של אות באלפבית.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_LengthAndIndex`: אורך המחרוזת ותו במקום מסוים
2. `Example02_PrintEachChar`: מעבר על כל התווים
3. `Example03_Substring`: חיתוך חלק ממחרוזת
4. `Example04_IndexOfAndContains`: חיפוש בתוך מחרוזת
5. `Example05_UpperLowerReplace`: אותיות גדולות, קטנות והחלפה
6. `Example06_CountLetter`: ספירת אות במחרוזת
7. `Example07_ReverseString`: היפוך מחרוזת
8. `Example08_Palindrome`: האם המילה פלינדרום
9. `Example09_CharCodes`: קודים של תווים
10. `Example10_StringsAreImmutable`: מחרוזת אינה משתנה

## איך מריצים

**ב-Visual Studio:**

1. פותחים את הקובץ `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט `Perek08` ובוחרים **Set as Startup Project**.
3. לוחצים על הכפתור הירוק **Start** (או על Ctrl+F5).
4. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

**משורת הפקודה (נדרש .NET 8):**

```bash
cd "פרק 8"
dotnet run
```
