# פרק 1: הוראות הדפסה ומשתנים

## בקצרה

- פקודות ההדפסה מציגות טקסט על המסך. אחת יורדת שורה בסוף, והשנייה לא.
- משתנה הוא תא בזיכרון עם שם, טיפוס וערך: מספר שלם, עשרוני, תו, מחרוזת וערך לוגי.
- בחילוק של שלמים התוצאה שלמה. כדי לקבל תוצאה מדויקת ממירים אחד המספרים לעשרוני.
- קליטת נתונים מהמשתמש מתבצעת בשתי הדוגמאות האחרונות, ולכן צריך להקליד בחלון ההרצה.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstPrint`: ההדפסה הראשונה
2. `Example02_WriteVersusWriteLine`: ההבדל בין הדפסה עם ירידת שורה להדפסה בלי ירידת שורה
3. `Example03_SpecialCharacters`: תווים מיוחדים בתוך מחרוזת
4. `Example04_IntVariables`: משתנים מטיפוס מספר שלם
5. `Example05_VariableTypes`: הטיפוסים העיקריים
6. `Example06_PrintingCalculations`: הדפסת תוצאות של חישובים
7. `Example07_SwapTwoVariables`: החלפת ערכים בין שני משתנים
8. `Example08_DivisionAndCasting`: חילוק והמרת טיפוסים
9. `Example09_ReadOneNumber`: קליטת מספר מהמשתמש
10. `Example10_ReadTwoNumbers`: קליטת שני מספרים וחישוב ממוצע

## איך מריצים

**ב-Visual Studio:**

1. פותחים את הקובץ `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט `Perek01` ובוחרים **Set as Startup Project**.
3. לוחצים על הכפתור הירוק **Start** (או על Ctrl+F5).
4. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

**משורת הפקודה (נדרש .NET 8):**

```bash
cd "פרק 1"
dotnet run
```
