# פרק 4: משפטי תנאי

> **מומלץ לבצע שיעור באתר קמפוס על הפרק הזה לפני שמתחילים.** [לקורס באתר קמפוס](https://app.campus.gov.il/learning/course/course-v1:MoE+EDU_Matric_ComputerScienceA_HE+2023_1/home), ובקורס פותחים את **פרק 4**.

## בקצרה

- משפט תנאי מריץ קוד רק אם תנאי מתקיים. אפשר להוסיף אחרת ושרשרת של תנאים נוספים.
- בשרשרת תנאים מתבצע בלוק אחד לכל היותר, ובתנאים נפרדים יכולים להתבצע כמה בלוקים.
- תנאים מורכבים נבנים בעזרת וגם, או ולא, ואפשר לכתוב תנאי בתוך תנאי.
- מחרוזות מושוות בעזרת סימן שווה כפול.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_SimpleIf`: משפט תנאי פשוט
2. `Example02_IfElse`: תנאי עם אחרת
3. `Example03_ElseIfChain`: שרשרת תנאים
4. `Example04_SeveralIfsVersusElseIf`: כמה תנאים נפרדים לעומת שרשרת
5. `Example05_NestedIf`: תנאי בתוך תנאי
6. `Example06_ConditionWithAndOr`: תנאי מורכב
7. `Example07_CompareStrings`: השוואת מחרוזות
8. `Example08_LeapYear`: שנה מעוברת
9. `Example09_BiggestOfThree`: הגדול משלושה מספרים
10. `Example10_RandomWithConditions`: הגרלה ותנאים

## איך מריצים בסטאקס

הקוד של הפרק נמצא בקובץ אחד, `Program.cs`, ואפשר להריץ אותו כמו שהוא.

1. פותחים את [סביבת הקוד של סטאקס](https://stacks.co.il/console/sandbox/).
2. לוחצים על **סביבת קוד** ← **פרויקט חדש** ← נותנים שם לפרויקט ← בוחרים בשפה **C#**.
3. מוחקים את הקוד שמופיע בקובץ שנפתח (אם יש בו קוד).
4. פותחים את [Program.cs של פרק 4](./Program.cs), מעתיקים את כל התוכן שלו, ומדביקים בקובץ.
5. לוחצים על **הרצה (F9)**. הפלט מופיע בחלון הפלט.
6. כל שורה בפעולה `Main` מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

אם מתקבלות שגיאות כמו `class, interface, enum, or record expected`, הפרויקט נוצר בשפה אחרת (Java). צריך ליצור פרויקט חדש ולבחור בו בשפה C#.

## הרצה ב-Visual Studio (לא חובה)

1. פותחים את `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. לוחצים לחיצה ימנית על הפרויקט `Perek04` ובוחרים **Set as Startup Project**, ואז **Start**.

משורת הפקודה (נדרש .NET 8):

```bash
cd "פרק 04"
dotnet run
```
