# פרק 6: לולאות while

## בקצרה

- לולאת while חוזרת כל עוד התנאי אמת, ומתאימה כשלא ידוע מראש מספר הסיבובים.
- צריך לאתחל את המשתנים לפני הלולאה ולקדם אותם בתוכה, אחרת הלולאה אינסופית.
- שימושים נפוצים: עבודה עם ספרות של מספר, אלגוריתם אוקלידס, הגרלות עד תנאי ולולאה עם דגל.

## הדוגמאות

הקוד נמצא ב-`Program.cs`. כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_FirstWhile`: לולאת תנאי ראשונה
2. `Example02_WhileWithSum`: סכום עד שמגיעים לגבול
3. `Example03_CountDigits`: ספירת ספרות של מספר
4. `Example04_SumOfDigits`: סכום ספרות
5. `Example05_ReverseNumber`: היפוך מספר
6. `Example06_GreatestCommonDivisor`: המחלק המשותף הגדול ביותר
7. `Example07_RollUntilSix`: הטלת קובייה עד שיוצא שש
8. `Example08_FlagLoop`: לולאה עם דגל
9. `Example09_DoublingUntilLimit`: הכפלה עד שעוברים גבול
10. `Example10_WhileInsideWhile`: לולאת תנאי בתוך לולאת תנאי

## איך מריצים

**ב-Visual Studio:**

1. פותחים את הקובץ `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט `Perek06` ובוחרים **Set as Startup Project**.
3. לוחצים על הכפתור הירוק **Start** (או על Ctrl+F5).
4. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

**משורת הפקודה (נדרש .NET 8):**

```bash
cd "פרק 6"
dotnet run
```
