# פרק 13: פולימורפיזם

## בקצרה

- פולימורפיזם: אותה קריאה לפעולה מתנהגת אחרת לפי הסוג האמיתי של העצם.
- משתנה, מערך או פרמטר מסוג האב יכולים להחזיק עצמים מכל היורשים.
- הפעולה שמופעלת נקבעת בזמן ההרצה לפי העצם, ולא לפי סוג המשתנה.
- כדי להפעיל פעולה שיש רק ליורש, ממירים במפורש לסוג היורש, אחרי שמוודאים שהעצם באמת מהסוג הזה.
- המחלקות כתובות בקובץ נפרד מהקובץ הראשי.

## הדוגמאות

הקוד נמצא ב-`Program.cs` (הדוגמאות) ו-`Classes.cs` (המחלקות). כל דוגמה היא פעולה סטטית נפרדת, ובפעולה `Main` הן מופעלות בזו אחר זו.

1. `Example01_SameCallDifferentBehavior`: אותה קריאה, התנהגות שונה
2. `Example02_ArrayOfParentType`: מערך מסוג האב
3. `Example03_MethodWithParentParameter`: פעולה שמקבלת פרמטר מסוג האב
4. `Example04_ShapesTotalArea`: סכום שטחים של צורות שונות
5. `Example05_Payroll`: חישוב שכר לעובדים מסוגים שונים
6. `Example06_ToStringIsPolymorphic`: גם פעולת הטקסט היא פולימורפית
7. `Example07_CastingToChild`: המרה מפורשת ליורש
8. `Example08_ReturnParentType`: פעולה שמחזירה את סוג האב
9. `Example09_FindTheBiggest`: חיפוש הצורה הגדולה ביותר
10. `Example10_Orchestra`: תזמורת אקראית

## איך מריצים

**ב-Visual Studio:**

1. פותחים את הקובץ `ThelmaYesodot11.sln` שבתיקייה הראשית.
2. בחלון Solution Explorer לוחצים לחיצה ימנית על הפרויקט `Perek13` ובוחרים **Set as Startup Project**.
3. לוחצים על הכפתור הירוק **Start** (או על Ctrl+F5).
4. בפעולה `Main` כל שורה מפעילה דוגמה אחת. כדי להריץ רק דוגמה מסוימת, מסמנים בהערה (`//`) את שאר השורות.

**משורת הפקודה (נדרש .NET 8):**

```bash
cd "פרק 13"
dotnet run
```
